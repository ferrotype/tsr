# S08 P1: ownership and storage feasibility

P1 is complete at the scope the plan's checkpoint table gives it. This record
states what exists, what was measured and what P2 starts with. No S08 acceptance
metric is supplied here: there is no semantic checker pass count, the storage
numbers come from a synthetic trace, not the subset census, and the reference
relater is a feasibility proof, not the P7 comparison.

Increments: [PR #14](https://github.com/iantocristian/ts-rust/pull/14) (printer
type-node path) and the P1 branch on top of it. Source baseline: Codex's
`48f6a9d` on `claude/s08-scaffold`. All observations use upstream
`1f70213d4922b434345f639b441681e470c7cfc1`.

## Storage families and constructors

`tsr_checker` now creates the types `NewChecker` creates, in its order, and the
constructor families the frozen storage trace needs. Every constructor is a
line-for-line port with a `// port:` marker; every unported branch is a named
`Error::Unsupported`, never a default.

| Family | Ported | Named boundaries |
| --- | --- | --- |
| Intrinsics, literals | `newIntrinsicType(Ex)`, `newLiteralType`, string/number/bigint interning (NaN cached apart, `-0` and `+0` one key), `getFreshTypeOfLiteralType`, `getRegularTypeOfLiteralType`, `createWideningType` | computed enum values |
| Objects | `newObjectType` for anonymous, reference, interface and tuple payloads; `newAnonymousType`; `setStructuredTypeMembers`; `getNamedMembers` with the ported symbol comparator | mapped, reverse-mapped, evolving-array and instantiation-expression payloads; `compareNodes` (declaration positions) |
| Tuples, references | `createTupleTargetType`, `getTupleTargetType`, `getTupleKey`, `createTupleType(Ex)`, `createTypeReference(Ex)`, `createNormalizedTypeReference`, `createNormalizedTupleType(Ex)` for required-only elements | `TupleNormalizer`; `[...X[]]` (needs `globalArrayType`) |
| Unions | `getUnionType(Ex)`, the union-of-union fast path, `getUnionTypeWorker`, `addTypesToUnion`, `removeRedundantLiteralTypes`, `getUnionTypeFromSortedList`, `addNamedUnions`, origins, aliases, `mapType(Ex)`, `insertType`/`containsType` | subtype reduction (`removeSubtypes`), constrained type variables, string literals matched by template literals |
| Template literals | `getTemplateLiteralType`, `getTemplateStringForType`, the pattern-literal predicates, `getGenericObjectFlags` | string mapping and substitution types, mapped-type genericity |
| Ordering | `CompareTypes`, `compareTypeNames`, `compareTypeLists`, `compareTupleTypes`, `compareSymbolsWorker`, `getSortOrderFlags`, `isReservedMemberName` | positions of declared symbols and labeled tuple elements |
| Signatures, symbols, links | `newSignature`, `newIndexInfo`, `newCallSignature` (declaration in the checker's own AST arena), `newSymbol(Ex)`, `ValueSymbolLinks` | everything reading source declarations |
| Constructor prefix | The 57 named type fields, five symbols, four signatures, two index infos and the type predicate `NewChecker` creates before `initializeClosures` | type mappers (P3); global resolvers, closures, `initializeChecker` (P2) |

Layout: one 32-byte common record per type plus one row in a payload table per
Go payload struct, following the embedding chain `TupleType ⊃ InterfaceType ⊃
TypeReference ⊃ ObjectType ⊃ StructuredType`; `Arc<[_]>` lists (ADR 0008);
`hashbrown` caches whose keys are upstream's key byte stream rather than its
xxh3 hash, so no collision can substitute a type and no hashing dependency is
needed until the census says the key bytes matter; checker symbols in the
adopted symbol arena; member tables in the checker's own `SymbolTables`.

## Owner-bound handles and exit tests

Results leave an operation only as `TypeRef`, `SignatureRef` and `NodeRef`
values that name their checker; every use validates that identity against the
lease before any read. `retain_*` produces `RetainedType`, `RetainedSymbol`,
`RetainedSignature`, `RetainedNode` and `RetainedTypeList`, each holding the
`Arc<CheckerOwner>`; `import_*` requires the exact owner and a live generation.
Internal caches hold only local ids, so a checker cannot retain itself.

Exit tests (debug and release): equal numeric slots in two checkers of one pool
generation rejected for every handle kind before any read; results outliving the
operation and the caller's owner handle, then owner and allocation counters
returning to baseline after the final drop; retirement refusing new operations
while retained storage stays live; checker-local id exhaustion failing before a
write; same-thread reentry versus other-thread contention; first queries reusing
`NewChecker`'s types and continuing `TypeCount`. The frozen-trace replay asserts
all 57 named type ids and flags against Go for both option sets.

## Storage measurement

`scripts/s08_families.py` runs two frozen traces of 121 constructor actions
(`data/s08/storage-families.json`; strict and non-strict null checks) on a Go
checker prepared by a replica of `NewChecker`'s type prefix and on the Rust
checker. The driver validates the replica against a real `NewChecker` over an
empty program on all 57 named types before running anything; the real checker
has exactly two more types (`globalThis`'s object type and `autoArrayType` from
`initializeChecker`, P2). Both runtimes agree on every root, on the named types
and on the creation counters (146 types, 32 symbols, 6 signatures; 144 types in
the non-strict trace). `families_tests.rs` replays the frozen Go observations
without Go.

Both sides then count live storage with the accounting frozen in
`data/s08/type-footprint.json`: each allocation once, with its capacity, by
family. Go structural bytes are struct sizes, slice and arena-chunk capacities
(replayed through `core.Arena`, including the runtime's size-class rounding) and
hinted-replica map allocations; Rust bytes are vector capacities, `Arc`
allocations and `hashbrown` allocation sizes. Strict trace:

| Family (count) | Go bytes | Rust bytes |
| --- | ---: | ---: |
| type records (146) | 0 (header inside payloads) | 8,192 |
| intrinsic (24) | 1,808 | 1,544 |
| literal (46) | 4,746 | 3,565 |
| anonymous (13) | 2,456 | 1,496 |
| reference (4) | 864 | 448 |
| tuple (6) | 2,720 | 2,256 |
| union (24) | 6,528 | 5,632 |
| type parameter (24) | 2,496 | 640 |
| template literal (5) | 760 | 936 |
| alias (Go 1, Rust 2) | 32 | 96 |
| type lists | 896 | 1,224 |
| type caches (88 entries) | 5,224 | 5,474 |
| **type storage** | **28,530** | **31,503** |
| symbols (32) | 3,216 | 7,890 |
| symbol tables (9) | 2,304 | 1,508 |
| signatures (6) | 768 | 664 |
| index infos (2) | 128 | 192 |
| type predicates (1) | 46 | 222 |
| value symbol links (22) | 3,848 | 8,396 |
| synthetic expression links | 0 | 76 |
| **checker total** | **38,840** | **50,451** |

The type-storage ratio is **1.104** (strict) and **1.143** (non-strict); the
0.80 target is not met on this trace. The checker AST arenas are unavailable on
both sides and reported as a named gap, not a zero.

Attribution, from the report rather than a model:

- The common-record table grew to 256 slots for 146 records: 3,520 of its 8,192
  bytes are growth slack. Without that slack type storage would be 27,983 bytes,
  0.98 of Go. Fixed-size pages, as the arenas use, bound the slack to one page.
- Every `Arc<[TypeId]>` pays a 16-byte header, and a tuple target holds two lists
  where Go clips one slice (1,224 versus 896 bytes of lists). Empty texts also
  allocate a 16-byte header.
- Rust's payload rows are smaller in every family where Go embeds the 56-byte
  header: type parameters 20 versus 104 bytes, literals 48 versus 88, unions 176
  versus 272, anonymous objects 88 versus 184.
- Unused occupied records are charged: the trace creates two alias records where
  Go's second `TypeAlias` is garbage.
- Outside type storage, inline 256-slot link pages (8,192 bytes for 22 links) and
  the symbol arena's doubling pages (62 slots for 32 symbols, 112-byte symbols
  versus 96) dominate; Go's chunks hold 33 slots because size-class rounding
  shapes its growth.

Transient budgets, prefix and trace separately (Go: `TotalAlloc` and malloc
calls; Rust: mimalloc requested allocations):

| Interval | Go bytes | Go mallocs | Rust requested | Rust retained |
| --- | ---: | ---: | ---: | ---: |
| `NewChecker` prefix | 18,800 | 148 | 19,331 | 12,247 |
| trace | 35,912 | 329 | 66,948 | 41,651 |

Rust requests 1.9 times Go's bytes during the trace; table doubling copies and
map rehashes are the visible mechanism. Rust's retained allocator delta (53,898)
exceeds its structural census (50,451) by the owner, lock and counter objects the
census does not charge.

Decision: keep this candidate as the measured baseline and do not start a
storage program now. The plan's stop rules put the integrated-candidate selection
at P7 over the real subset distribution; the mechanisms above (paged tables, a
24-byte record, boxed or narrower link pages, one shared empty text) are the
recorded levers for that step. The report and raw run are archived under
`tools/s08/results/p1-storage/`.

## Reference relater feasibility

`tools/s08/relater-prototype` (`s08_relater_prototype`, `#![forbid(unsafe_code)]`)
builds a type graph of `Rc` cells whose edges are `Weak`, resolves members
lazily through a `OnceCell` while allocating into the graph, and ports the core
of `checkTypeRelatedToEx`, `isRelatedToEx`, `recursiveTypeRelatedTo`,
`resetMaybeStack`, `propertiesRelatedTo`, `propertiesIdenticalTo` and
`isDeeplyNestedType` for object and primitive types in all five relation modes.

On the frozen fixtures `recursive-objects` and `recursive-mismatch` it reproduces
the Go-observed top-level ternaries (Maybe on the cold recursive relation, True
from the cache on repeat, identity's order-free key), boolean results, per-mode
cache entry counts and result-flag multisets, and diagnostic counts for all four
actions of every mode. A 1,000-level chain relates on a 256 MiB thread and stops
at upstream's 100-level assumption limit with the same cache growth. Recorded
failure behavior: a panicking resolver publishes nothing and caches nothing,
and subsequent reads reject its consumed resolver instead of publishing empty
members; an escaped cell outlives the graph but its edges fail with
`Error::Released`, which is why the alternative must couple results to the owner
(ADR 0007); an undeclared
member type is an error. The P7 experiment (`data/s08/relater-fixtures.json`)
builds on this API; no measurement was taken.

## Verification

Debug and release: 38 `tsr_checker` tests plus two compile-fail doctests, 6
prototype tests, and the arena, AST, jsnum, printer and node-builder suites;
locked workspace build; Clippy with all targets and features and warnings denied;
Rust 1.96 check; formatting; 35 S08 Python tests including the new adversarial
oracle checks (reordered, missing or altered roots, counters and families);
ledger validation and committed views. Mapped upstream functions rise from 1,946
to 2,041. Four-target CI runs on the PR.
