# S08 E2 acceptance capture

E2 now has a correctness producer, separate from the P5 development reports.
It grades all 9,369 acceptance variants; all 1,359 informational variants are
captured and reported but do not enter a gate. No threshold or selection changed.

`cargo xtask run e2` still observes the S07 frozen-subset requirement. When
`target/s08/e2/corpus` exists, it also replays that capture and its runtime
obligations. With no capture, correctness metrics remain unavailable with a
command hint. An incomplete, stale or malformed capture fails the producer.
This command does not start a full corpus run implicitly, including on CI.

## Capture once, replay before recording

The full native capture needs one new observation mode. Existing P5 archives
remain valid development evidence, but cannot supply a public `TypeToString`
result they did not observe.

```sh
python3 scripts/s08_baselines.py --output target/s08/e2-native \
  --include-informational --walker-inputs --error-inputs --public-type-strings
python3 scripts/s08_e2.py preflight --native target/s08/e2-native
python3 scripts/s08_e2.py capture --native target/s08/e2-native
python3 scripts/s08_e2.py verify
cargo xtask run e2
cargo xtask status
```

The loading-request default is the complete frozen S07 preparation at
`target/s07-subset/review/loading-requests.candidate.json`. Pass
`--loading-requests PATH` if that preparation is elsewhere. The preflight
checks each request hash against `data/s08/baseline-requests.json`, native pin,
adapter sources, ordered inventory and public display coverage before building.

`capture` executes the bounded comparator/recursion obligations first, then
builds and copies the Rust corpus executable once. Cases have independent
processes, deadlines, raw output and atomic completion records. Use `--resume`
with identical arguments after interruption. It keeps the captured executable;
changed code requires a new capture directory. The default per-case timeout is
60 seconds; changing it requires a fresh capture.

For a cheap integration check, give the native command `--smoke`, choose separate
native/Rust output directories, and give the E2 commands `--smoke`. Such reports
contain **no acceptance metrics**, regardless of their match count. Never place
a smoke capture at the default acceptance path.

## What the metrics observe

- `types_parity`: exact `.types` and `.symbols` outcomes plus the independently
  executed query schedule, with only numeric type IDs excluded as in P0.
- `errors_parity`: byte-exact `.errors.txt`, structured pre/post/render
  diagnostics, original input selection and pretty-print option. JavaScript emit
  remains explicitly unexecuted; an observable pre/post-emit difference fails.
- `type_to_string_parity`: default public `TypeToString` on each type returned by
  the normal type walker. Both implementations retain those results and display
  them **after** the ordinary type/symbol baseline walks. They do not repeat type
  lookup or insert work into the existing query sequence. File, kind, range,
  order and output bytes are compared, and coverage is checked against all
  actual nonabsent type queries. Native `NoTypesAndSymbols` cases carry an
  explicit disabled outcome; a missing requested display is a failure.
- `comparators`: the frozen P0 residual families, all union matrices and exact
  permutations, including the foreign-checker boundary, executed by the existing
  production comparator adapter. Coverage counts live in the obligation manifest.
- `recursion_fixtures`: all four native deep-relation cases at 64/256/1024/4096
  on a 512 KiB Rust worker stack, comparing complete relation groups, post-action
  display, counters and diagnostics. The named Rust recursion, resolution-stack,
  reentry and panic-after-growth tests must also pass in debug **and** release.
- `divergences_approved`: complete accepted results and no unused acceptance
  approval witnesses. Informational approvals are reported without affecting
  this gate. The ledger requires owner metadata, pin, scope and exact native/Rust
  hashes for each named variant and metric. Globs cannot approve arbitrary future
  bytes. Failures and unexecuted operations cannot be approved as parity.

The three parity ratios use the full acceptance denominator, including failed
variants. The report retains raw match/difference/failure counts and exact
approval identities even when an approved difference qualifies for acceptance.
The divergence ledger is hashed at grading and declared as a producer input;
changing it invalidates tracker evidence and requires comparison again, not a
checker rerun when the captured sources are otherwise current.

The verifier recomputes scores from raw artifacts, checks source snapshots and
binary/input hashes, and rejects stale inputs. It does not trust summary booleans.
The obligation manifest is `data/s08/e2-obligations.json`; actual test inventories
are checked before execution. No P7 measurement, full S08 completion or S09
instrumentation result is implied by these correctness metrics.

## Initial validation (2026-09-14)

The five-variant smoke capture matched all three acceptance cases in all three
parity domains, including 322 public `TypeToString` observations. The two
informational cases remained separate: one had matching errors and explicitly
disabled type/symbol baselines; one retained native option rejection. The report
emits an empty acceptance metric map. Full verification rejects this selection
as an incomplete denominator.

All eight residual comparator families, seven union matrices and 77 permutations
matched. All four native deep fixtures matched complete groups and diagnostics;
the 20 named Rust checks passed across debug and release. The S08 script suite
passed (115 tests, one existing skip), as did targeted adapter clippy with
warnings denied, formatting and ledger validation.

The [114,768-byte diagnostic archive](../tools/s08/results/p6-e2-smoke.tar.xz)
contains the native and Rust requests, observations, invocation output and
comparison reports. It deliberately omits executables and source snapshots, so
it cannot activate the acceptance producer or replace a complete capture.
The complete local captures are `target/s08/e2-smoke-native-01` and
`target/s08/e2-smoke-03`; `verify --smoke` replayed the latter successfully.
The scripts and Rust adapters used to produce these results are committed with
this change. The full 10,728-variant run has not been started.
